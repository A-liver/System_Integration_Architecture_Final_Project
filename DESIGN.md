# Design direction

Answers given by the project owner, transcribed. antislop treats this file as direction.

## Owner's answers

- **Identity:** text placeholder name, "University Registration and Payment". No invented school name or logo.
- **Personality:** sharp and utilitarian.
- **Palette:** blue and white.
- **Typography:** serif headings, sans body.

Dial: ENERGY 1 / RHYTHM 2 / MOTION 1

## Design Read

Reading this as: enrollment work tool for university students and registrar staff, in a sharp utilitarian registrar language of blue on white, dial ENERGY 1 / RHYTHM 2 / MOTION 1.

## Decision reasons (R-31)

| Decision | Reason |
|---|---|
| Color | Owner chose blue and white. One deep blue carries structure and actions so status and totals read first. |
| Accent | One red, used only for problems (declined, rejected, outage), so a student can spot trouble at peak enrollment. |
| Headings: Source Serif 4 | Owner chose serif headings. It has the look of a printed registrar form and stays compact at small sizes. |
| Body: IBM Plex Sans | Clear at table density, with tabular figures so fees and seat counts line up. |
| Identity motif: the enrollment slip | A registrar's paper slip with a dashed tear line and a square status stamp. It repeats on every registration screen because the slip is what a student is actually trying to get. |
| Layout | Ledger tables with a slip column, because the job is comparing courses and watching one total. Pages differ by task: list, slip, or queue. |
| Spacing | Tight rows for scanning, large gaps only between task areas. |
| Cards | Not used for lists. The slip is the only boxed object, so it is the focal point. |
| Radius 2px, no shadows | Sharp forms; rules and borders mark structure. |
| Icons and illustration | None. Text labels are clearer here and nothing needs decorating. |
| Motion | Hover and focus only (MOTION 1), so a form under load never feels slower than it is. |
| Light/dark toggle | No strong reason to fix one theme, and students register at all hours. |
